## B. Design system / tokens

**Confirmed matches (no action needed):** primary navy `#14213D`, primary-dark `#0B1526`, accent gold `#FCA311`, accent-dark `#E0900C`, on-accent black, success `#10B981`, danger `#EF4444`, background `#F8FAFC`, surface white, text-muted `#64748B`; all activity-hero gradients; all module accent colors (speaking/writing/listening/reading); Outfit (body) / Newsreader (display/headline) font pairing via `google_fonts`; the three base radius tokens (`sm=8 / md=12 / lg=20`, matching `--radius-sm/--radius/--radius-lg`); navy-tinted shadow tokens; primary-button navy resolution. Dark mode is a pure Flutter addition — the web has no `prefers-color-scheme`/`[data-theme]` support at all, so Flutter's dark theme is a reasonable native-only enhancement, not a parity gap.

**Web CSS cascade note** (explains why "the token" is sometimes ambiguous): `style.css` has an original `:root` (line 6, blue theme) overridden by a later "BLACK & GOLD ELEGANCE" global override block (line 2529, navy/gold — authoritative for site chrome/nav/footer), with a further override scoped just to `.btn-primary` ("Reduce gold dominance," ~line 2951) that wins for that one selector, making primary buttons resolve to navy rather than gold. `landing.html` additionally defines its own separate, lighter *content* palette inline (see section A above) used only within the page body, not the chrome. Three different cascading layers, not one `:root` — important context for anyone re-deriving a token later.

## C. What this matrix does NOT cover

Per-screen visual review beyond the landing page (activities, dashboard, resume flows, Skill-Up, roleplay, etc.) was not separately re-audited pixel-by-pixel this phase — those screens' design tokens are covered by section B's confirmed-match list (the shared theme applies everywhere), but their layouts were not individually re-compared against updated web templates in this pass. This should be scoped as explicit follow-up work in the roadmap (see `UPDATED_WEB_MOBILE_CONVERSION_ROADMAP.md`) rather than assumed clean.
